CYD Weather 1.0.0 — คู่มือ
จอเรดาร์ฝน + พยากรณ์อากาศ + ระดับน้ำ บนบอร์ด CYD (ESP32-2432S028R จอ 2.8")
by tee & claude

== เปิดครั้งแรก ==
1. แตะ + ทั้ง 4 มุมเพื่อปรับทัช (ทำครั้งเดียว)
2. ต่อ Wi-Fi: จอแสดงรายชื่อ Wi-Fi แตะเลือก แล้วพิมพ์รหัสด้วยคีย์บอร์ดบนจอ
   (ใช้ Wi-Fi 2.4 GHz เท่านั้น) หรือกด "Use phone setup" แล้วตั้งผ่านมือถือ
3. ค่าเริ่มต้นคือกรุงเทพฯ: กดปุ่มเฟือง (ขวา) > Location > Change เพื่อเลือกจังหวัด
4. ครั้งแรกบอร์ดต้องโหลดแผนที่เอง ราว 45 วินาทีต่อระดับซูม แล้วเมฆฝนจะตามมา
   (โหลดครั้งเดียว เก็บไว้ในบอร์ด ปิดเปิดใหม่ไม่ต้องโหลดอีก)

== หน้าจอหลัก (Rain) ==
- เมฆฝนเคลื่อนไหว: 2 ชั่วโมงที่ผ่านมา เล่นวนแล้วค้างภาพล่าสุด 3 วินาที
  มุมขวาบนบอกว่าภาพนี้เมื่อกี่นาทีก่อน (เช่น -30 MIN) · เป็นข้อมูลย้อนหลัง ไม่ใช่พยากรณ์
- สีฝน: ฟ้า = เบา ไล่ไปจนแดง/ม่วง = หนัก (แถบ Light - Heavy ด้านล่าง)
- เครื่องหมาย + สีขาวกลางจอ = ตำแหน่งที่เลือก
- แตะแผนที่ (ที่ว่าง) = ซ่อน / แสดงการ์ดอากาศ
- ปุ่ม + / - ขวามือ = ซูม 3 ระดับ (ระดับใหม่ต้องรอโหลดแผนที่ครั้งแรก)
- การ์ดบน: อุณหภูมิ รู้สึกเหมือน ปริมาณฝน ความชื้น โอกาสฝน ลม ลมกระโชก ความกดอากาศ ทัศนวิสัย
- การ์ดล่าง: พยากรณ์ 3 วัน สูงสุด/ต่ำสุด และโอกาสฝน

== หน้า Water (แท็บบนจอ) ==
- จุดเล็ก = สถานีวัดน้ำปกติ / น้ำน้อย
- วงกลมน้ำเงิน = น้ำมาก · วงกลมแดงกระพริบ = ล้นตลิ่ง
- สี่เหลี่ยมมีตัวเลข = เขื่อนใหญ่ และ % น้ำในเขื่อน
- แตะจุด = ชื่อสถานี ระดับน้ำเทียบตลิ่ง แนวโน้มขึ้น/ลง · แตะเขื่อน = % น้ำ น้ำเข้า/ออกต่อวัน
- มีเฉพาะในประเทศไทย อัปเดตสถานีทุก 30 นาที เขื่อนวันละครั้ง

== ป้ายซ้ายบน ==
Live = ข้อมูลครบ · Sync = กำลังโหลด · Retry = ยังขาดบางอย่าง เดี๋ยวลองใหม่เอง · Offline = Wi-Fi หลุด

== ตั้งค่า (ปุ่มเฟือง) ==
- Location: เลือกภาค > จังหวัด หรือ Coordinates พิมพ์ละติจูด/ลองจิจูดเอง (ใช้ได้ทั่วโลก
  แต่เรดาร์มีเฉพาะประเทศที่มีเรดาร์ และเวลาบนจอเป็นเวลาไทย)
- Wi-Fi: เปลี่ยนเครือข่าย
- Touch: ปรับทัชใหม่ (ถ้ากดไม่ตรง)
- Screen: กลับหัวจอ (สำหรับวางกลับด้านสาย USB)

== แหล่งข้อมูล ==
เรดาร์ฝน RainViewer · อากาศ Open-Meteo · แผนที่ Esri / OpenStreetMap · ระดับน้ำ ThaiWater (สสน.)
บอร์ดดึงข้อมูลเองผ่านอินเทอร์เน็ต ไม่มีค่าใช้จ่าย ไม่ต้องสมัคร

== ปัญหาที่พบบ่อย ==
- กดไม่ตรง: เฟือง > Touch > Start แล้วแตะ + ทั้ง 4 มุม
  (ถ้าเข้าเมนูไม่ได้เลย: ติดตั้งใหม่แบบ "ล้างเครื่อง")
- ไม่มีแผนที่ / ขึ้น Retry นาน: เช็ก Wi-Fi และอินเทอร์เน็ต บอร์ดจะลองใหม่เองทุก 30 วินาที
- ไม่มีเมฆฝนบนจอ: อาจแค่ไม่มีฝนตอนนี้ ดูมุมขวาบนว่าเวลาภาพล่าสุดขึ้นไหม
